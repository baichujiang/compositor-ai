# Demo

Open Mountain-demo.comp in Compositor AI. This small, procedurally drawn test scene has two mountain peaks and a separate Moon layer. It contains no user photographs.

Try “Set the Moon layer to 65% opacity.” Enable Include canvas image, then ask “Move the moon above the second mountain peak, with a 20-pixel gap between the moon's bottom edge and the peak.” Undo with ⌘Z. Work on a copy if you want to retain the initial scene.
